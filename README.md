# PLP Python Week 7: Working with Files

- `my_notes.py`: writes three notes, appends a fourth, reads them back and counts the lines.
- `my_notes.txt`: the notes file generated by `my_notes.py`.
- `report_builder.py`: reads `hubs.csv`, calculates pass/fail counts and the average, and writes `report.txt`.
- `hubs.csv`: the learner data (name, hub, score).
- `report.txt`: the report generated by `report_builder.py`.

**What if `"a"` were changed to `"w"` in Question 1?**
Mode `"w"` overwrites the file, so the first three notes would be erased and `my_notes.txt` would contain only "I added this later". The line count would then be 1 instead of 4.
